Antibiotic Susceptibility Analysis (Disk Diffusion)
Background
This project is based on a microbiology practical the antibiotic resistances and the antibiotic disk test of bacteria 

Bacterial species tested included:
-Escherichia coli
-Staphylococcus epidermidis
-Bacillus subtilis
-Enterococcus faecalis

Objective
To determine:
-Which antibiotic is most effective
-Which bacteria show the highest resistance

Method Summary
-Zones of inhibition (mm) were measured for different antibiotic discs placed on agar plates inoculated with bacteria.

Data Analysis
The dataset was structured and analysed using Python.
Python (pandas, matplotlib) was used to:
-Clean the dataset (remove missing values & duplicates)
-Standardise bacterial and antibiotic names
-Calculate average zones of inhibition
-Visualise antibiotic effectiveness

Key Findings
-Antibiotics with larger average zones showed higher effectiveness
-Bacteria with smaller average zones showed higher resistance
Example: E. coli showed high susceptibility to streptomycin (large inhibition zone)

Relevance
This project demonstrates the integration of biotechnology knowledge and data analysis
